# Learn Thyself - Desktop Organizer

A comprehensive web-based desktop organizer application that helps you track various aspects of your daily life.

## Features

- **Habit Tracking**: Monitor daily activities and build positive habits
- **Mood & Energy Tracking**: Log your emotional state and energy levels
- **Financial Tracking**: Keep track of daily spending
- **Life Events**: Record important moments and experiences
- **Cloud Sync**: Data is synchronized across devices using Firebase
- **User Authentication**: Secure login system with account management

## Live Demo

Visit the live application: [Learn Thyself Desktop Organizer](https://[your-username].github.io/[repo-name]/)

## Technologies Used

- HTML5, CSS3, JavaScript
- Firebase (Authentication, Realtime Database)
- Tailwind CSS
- Google Fonts

## Setup

1. Clone the repository
2. Open `index.html` in a web browser
3. Create an account or sign in to start tracking your habits

## Firebase Configuration

The application uses Firebase for data storage and user authentication. The Firebase configuration is already set up in the code.
